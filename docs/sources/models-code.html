Retrieval methods on this page

Why each source is fetched the way it is. The methods overview explains the order of preference and the rules every collector follows.

Release feed per repo or package

How it works: GitHub publishes github.com/{owner}/{repo}/releases.atom for every repository with no authentication; PyPI publishes an RSS feed per package. We poll one feed per tracked repo or package.

Why this method: A release is the earliest reliable sign that a model or feature has landed in the tools you actually use (vLLM often supports a new model before any blog post). The Atom feeds avoid the GitHub REST API limit of 60 unauthenticated requests per hour.

Watch-outs: Release candidates and nightlies are noisy, so tags containing rc, dev or nightly are skipped unless they are major versions.

Used here by: GitHub releases (~25 repos, e.g. vLLM), PyPI releases (e.g. anthropic)

Raw file diff

How it works: Fetch the raw file (for example CHANGELOG.md on raw.githubusercontent.com), diff it against the last version, and parse the new version headings.

Why this method: Some tools document releases only in a changelog file (Claude Code). A raw file is plain text, supports ETag caching and needs no HTML parsing.

Watch-outs: Headings must follow a version pattern; if the format changes, the parser falls back to sending the raw diff to the LLM.

Used here by: Claude Code changelog

Public JSON API (no key)

How it works: Call a public endpoint that returns JSON: HN Algolia search, HF Daily Papers and trending, OpenRouter /models, the Greenhouse, Lever, Ashby and SmartRecruiters job-board APIs, the Bluesky AppView, npm.

Why this method: Fields we rank on (points, upvotes, prices, context length, salary, location) come back typed, with no scraping. Job-board APIs exist precisely so that postings get syndicated, so polling them is the intended use.

Watch-outs: Respect each provider's rate limit and cache responses. A schema change shows up as zero items, which the source health check reports.

Used here by: HF trending models, HF trending spaces, OpenRouter models, OSS Insight trending repos, npm latest (e.g. @anthropic-ai/sdk)

Dataset snapshot diff

How it works: Download a published dataset (the Arena leaderboard on Hugging Face, the Indeed Hiring Lab CSV), store it, and diff it against the previous copy.

Why this method: Leaderboards and labour-market indices are published as data, not articles. A diff yields facts with a source, such as 'model X entered the top 5' or 'AI share of postings up 0.4 points', and the CC-BY licences allow reuse with attribution.

Watch-outs: Weekly or monthly cadence only. Column changes are caught by schema validation.

Used here by: Arena leaderboard dataset

Official API with a free key

How it works: Same as a public JSON API, but with a free registration key kept in Secret Manager: Reed, USAJobs, Adzuna, Semantic Scholar, Artificial Analysis (and Congress.gov later).

Why this method: It is the provider's sanctioned route: the terms allow it, the data is complete (Reed returns full descriptions and salaries) and quotas are documented, so calls can be planned.

Watch-outs: Quotas are tight on some (Artificial Analysis 100 requests a day, Adzuna 2,500 a month). Some require attribution, which goes in the brief's footer.

Used here by: Artificial Analysis
